================================================================
 OnionBit {{VERSION}} — Windows x64
 Anonymous BitTorrent client, native in Rust (Tribler port)
================================================================

DEMARRAGE RAPIDE
  1. Extraire le zip complet dans un dossier (ex. C:\OnionBit).
  2. Double-cliquer « OnionBit.exe » (a la racine) — l'interface
     graphique s'ouvre et demarre le daemon automatiquement.
  3. Premier lancement : l'etat est cree dans state\ a cote des
     lanceurs (configuration.json, api key, base SQLite, logs).

TROIS LANCEURS A LA RACINE — choisissez votre interface :
  OnionBit           Interface graphique Windows (Flutter) —
                     demarre le daemon au besoin. Usage courant.
  OnionBit Web       Interface web : demarre le daemon s'il ne
                     tourne pas puis ouvre le navigateur sur
                     http://127.0.0.1:8085/ — meme UI, sans installer
                     l'application desktop. Ideal aussi pour un second
                     poste du reseau local.
  OnionBit Daemon    Backend seul : console de logs + icone systray,
                     sans UI. Pour les usages avances (API,
                     onionbit-cli, pilotage a distance).

CONTENU
  OnionBit.exe / OnionBit Daemon.exe / OnionBit Web.exe
                        Lanceurs racine portables (resolvent windows\
                        relativement — le bundle se deplace tel quel)
  OnionBit.portable     Marqueur du mode portable : state\ et data\
                        vivent a cote. Ne pas supprimer.
  LISEZMOI.txt          Ce fichier
  build-manifest.json   Version, commit, toolchain du build
  windows\              Payload Windows (exe, dll, web\) — ouvrir via
                        les lanceurs racine, pas besoin d'y entrer
  state\, data\         Votre etat et vos donnees — crees au premier
                        lancement, a sauvegarder avec le bundle
  LICENSE               GPL-3.0-or-later

INTERFACE WEB — CLE API
  La cle API est injectee automatiquement par le daemon dans la page
  servie — rien a saisir. Pour la desactiver :
  api/web_ui_inject_key = false dans state\configuration.json, et
  saisir alors la cle « api/key » dans l'UI (ou ?key=<cle>).

LIGNES DE COMMANDE (optionnel, tout est dans windows\)
  windows\onionbit-daemon.exe                 daemon seul (API sur
                                              http://127.0.0.1:8085)
  windows\onionbit-daemon.exe --open-webui    idem + ouvre l'UI web
  windows\onionbit-daemon.exe --web-ui-dir D  sert une UI web depuis D
  windows\onionbit-cli.exe --help             commandes disponibles
  Variables d'environnement utiles :
    ONIONBIT_DAEMON_EXE=<chemin>      force l'exe du daemon pour l'UI
    ONIONBIT_API_KEY=<cle>            cle d'API (sinon lue depuis
                                    state\configuration.json)

ANONYMAT
  Par defaut les telechargements ajoutes via l'UI utilisent le mode
  anonyme (circuits a sauts multiples). Le traffic pair, DHT et
  trackers passe dans le tunnel — aucune connexion UDP clearnet vers
  les pairs n'est ouverte en mode anonyme.

AVERTISSEMENT — VERSION ALPHA
  Logiciel en developpement actif. L'anonymat est valide en banc
  d'interop avec Tribler 8.x mais n'est pas equivalent a Tor face a
  un adversaire global. Ne pas utiliser pour des besoins critiques.
  Les tests longue-duree (stress, coupures) sont encore en cours.
