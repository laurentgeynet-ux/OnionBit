# docs/plans/

Ce dossier contient la documentation interne de pilotage du projet
(roadmap détaillée, plans d'étapes, catalogues de bancs, journaux de
campagne) — **non publiée** : les fichiers sont ignorés par git
(`docs/plans/*` dans `.gitignore`, ce README excepté).

Les références à `docs/plans/…` dans le code, les ADR et le CHANGELOG
restent valides pour quiconque détient le dépôt complet.
